# 🌍 Disaster Preparedness System

An offline-first disaster preparedness and emergency response platform designed to provide users with essential emergency resources even when internet connectivity is unavailable.

## 📌 Project Overview

The Disaster Preparedness System helps users stay informed and prepared during natural disasters by providing offline access to emergency guides, personal medical information, preparedness checklists, offline maps, and SOS functionality.

The application is designed to continue working during network outages and synchronize data with the server once an internet connection is restored.

---

## ✨ Features

- 📖 Offline Disaster Guides
- 🩺 Emergency Medical Card
- 🎒 Emergency Kit Checklist
- 🆘 SOS Emergency Assistance
- 🗺️ Offline Maps
